# SoftStock
An AI-assisted inventory monitoring and restocking web app for Softbound Café.
PTF50 Final Project, Angeles University Foundation.

## Team
- Member 1: Frontend / UI
- Member 2: AI / ML (Transformers.js)
- Member 3: Inventory system and integration

## Who edits what
| File | Owner |
|------|-------|
| index.html, css/style.css, js/dashboard.js | Member 1 |
| js/ai.js | Member 2 |
| js/storage.js, js/seed.js, js/inventory.js | Member 3 |
| js/main.js | Shared (coordinate first) |

## Run locally
Use the VS Code "Live Server" extension on index.html. Opening the file directly will not work (ES modules need a server).
